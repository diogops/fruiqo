## 4. Recomendação

Usar **Open Library como fonte primária** de metadados de livros nos dois cenários: os dados bibliográficos (título, autor, assunto, ano) estão sob CC0 — licença permissiva confirmada, sem restrição de finalidade, o que já cobre o uso em ranking local e, diferente do Google Books, não deixa em aberto a questão do envio a um LLM (PERMITIDO, não apenas "condicionado"). A API não exige chave, não impõe branding obrigatório (só "courtesy link") e as únicas condições são operacionais (User-Agent identificado — TOS-REQ-60, respeito ao rate limit e ao caráter não-bulk — TOS-REQ-61/62).

Usar **Google Books como fonte secundária/fallback** (ex.: quando a Open Library não tiver o título, ou para enriquecer sinopse/capa de maior resolução), sempre com o logo "powered by Google" e link obrigatórios (TOS-REQ-63), respeitando o limite de cache do cache-control header (TOS-REQ-64), mantendo o app gratuito (TOS-REQ-65) e **sem enviar nenhum dado do Google Books a um LLM** até PEND-30 ser resolvida — o mesmo padrão de cautela já aplicado ao TMDB antes de D-17. Capas da Open Library seguem o mesmo bloqueio para uso com LLM multimodal (PEND-31) até confirmação de licença; podem ser exibidas normalmente na UI do app (isso não é uso "com LLM").
